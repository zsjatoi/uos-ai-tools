3D Ball Shooting Game

Aim is fixed straight ahead. Fire a ball at the moving red target by clicking inside the game area, or by pressing the Spacebar or Enter key while the game area has focus. Hitting the target's bullseye scores a point with a colourful explosion; missing it briefly dims the screen edges. This is a fast-paced 3D game and is best played by sighted users; a running score and a hit/miss announcement are provided as text below for anyone using a screen reader.
