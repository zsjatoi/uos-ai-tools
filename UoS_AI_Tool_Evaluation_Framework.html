Note for reviewers: In this prototype, data is not yet connected to a live SharePoint List. In full deployment, this button would send all scores, notes, and the overall verdict to a Microsoft List via Power Automate, creating a permanent searchable record of every evaluation. A Power BI dashboard on top of that list would allow the team to compare tools, track evaluations over time, and report to senior leadership — mirroring the Microsoft List and Power BI dashboard already in use for the Thesis Support Service.
